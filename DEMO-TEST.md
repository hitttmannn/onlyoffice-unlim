# Проверка редакторов без второго Nextcloud

Используется встроенный demonstration example ONLYOFFICE, только в контейнере
onlyoffice-unlim-stage-docs-1. Он не является хранилищем рабочих документов.
Порты и рабочий коннектор Nextcloud не меняются; JWT не отключается.

```sh
git pull --ff-only
python3 scripts/demo.py start
curl -s -o /dev/null -w 'example HTTP %{http_code}\n' http://127.0.0.1:18080/example/
```

Если сервис не найден, скрипт покажет supervisor status и завершится. Не
выполнять start all и не применять команды к production контейнеру.

На своём компьютере (не в shell nc) открыть SSH-туннель, подставив фактический
адрес и доступного SSH-пользователя:

```sh
ssh -N -L 18080:127.0.0.1:18080 root@АДРЕС_NC
```

Оставить туннель открытым, в браузере своего компьютера перейти на
http://127.0.0.1:18080/example/ . Не открывать порт 18080 наружу и не менять
его binding на 0.0.0.0. Если локальный порт занят, слева в -L можно указать 28080,
а затем открыть http://127.0.0.1:28080/example/ .

## Приёмочные действия

1. Создать тестовый DOCX, внести уникальную строку, например OO10-save-001.
   Закрыть редактор во всех вкладках, дождаться сохранения (обычно несколько
   секунд), затем открыть документ снова со страницы example и сверить строку.
   Скачать файл и проверить, что строка есть в скачанной копии. Не считать
   отображение текста в ещё открытой вкладке доказательством сохранения.
2. Аналогично проверить XLSX (число и формулу) и PPTX (текст на слайде).
3. Открыть один документ в двух браузерных сессиях под разными тестовыми
   пользователями, если example позволяет их выбрать. Проверить обмен правками,
   закрыть обе сессии и проверить повторное открытие.
4. Проверить PDF export, кириллицу и внешний вид тестовых документов.
5. Записать фактический результат: открывается / редактируется / сохраняется /
   скачанная копия содержит изменения. При ошибке сообщить её точный текст,
   не отправляя JWT, полный URL с токеном или private.env.

Мобильную проверку выполнять отдельно на реальном устройстве через доступный
ему защищённый туннель. Смена размера окна desktop браузера не заменяет Android
Chrome/iOS Safari. Нельзя считать наличие mobile UI успехом редактирования.
Интеграция с Nextcloud и её callbacks этими действиями НЕ подтверждается.

После тестирования отключить пример:

```sh
python3 scripts/demo.py stop
```

Пример может хранить загруженные документы в слое тестового контейнера — не
пересоздавать его до скачивания нужных результатов. Рабочие документы не
загружать. Включение demo не входит в production-сборку и не даёт основания
переключать Nextcloud.

Основание: официальный пример тестирования до интеграции
https://www.onlyoffice.com/images/templates/whitepapers/pdf/integration_example.pdf
Имя supervisor-сервиса определяется по фактическому контейнеру, а не угадывается.
