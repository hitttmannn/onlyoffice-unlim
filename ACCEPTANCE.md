# Приёмка — все пункты пока НЕ ВЫПОЛНЕНЫ на nc

| Проверка | Условие успеха |
|---|---|
| Происхождение | Реальный пакет 10.0, digest и архитектура записаны; source SHA соответствуют пакету |
| Лицензии | Все bundled компоненты и шрифты разрешены к выбранному распространению; исходники доступны |
| Изоляция | Только 127.0.0.1:18080, отдельные тома и БД; production не изменён |
| HTTP | healthcheck true, api.js доступен |
| Документы | На тестовом Nextcloud создать DOCX/XLSX/PPTX, изменить, закрыть, дождаться callback, открыть и сверить данные |
| Конверсия | DOCX/XLSX/PPTX → PDF, кириллица, шрифты, таблицы, формулы и изображения проверены |
| Coediting | Два разных пользователя видят правки; изменения переживают перезапуск staging |
| Мобильный web | Реальные Android Chrome и iOS Safari: изменить и сохранить каждый формат, повторно открыть на desktop |
| Native mobile | Отдельно проверить подключение Nextcloud/WebDAV, сохранение, конфликты; не смешивать с web |
| JWT/TLS | Корректный токен работает, неверный/отсутствующий отклоняется API; callbacks с доверенным TLS |
| Лимит | Проверить исходную ветку обработки лимита и 21+ реальных сессий на стенде с достаточной памятью |
| Ресурсы | Нет OOM/restart, MemAvailable не ниже 512 MiB, нет постоянного swap-in/out или ухудшения Nextcloud |
| Backup | Восстановление копии 9.2.1 на изолированном стенде проверено |

21+ сессий не запускать на production nc даже после увеличения памяти до заявленных 8 GB RAM. Для доказательства лимита
нужен стенд с достаточными ресурсами; здоровье HTTP не подтверждает редактирование.
При нехватке памяти тест остановить, а результат считать неподтверждённым.
Для ресурсов: `vmstat 1`, `docker stats`; журналы и счётчики OOM проверять локально.
Отчёт должен включать дату, image digest, source SHA, версии клиентов, результаты
и ожидаемое/реальное поведение, без JWT, персональных документов и токенов.
