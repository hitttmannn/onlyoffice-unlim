# onlyoffice-unlim — «Простые документы» для Nextcloud

**Русский** · [English](README.md) · [Инструкция по установке](docs/INSTALL.ru.md)

Небольшой мобильный интерфейс DOCX/XLSX для Nextcloud на открытом plugin API
настольного движка ONLYOFFICE. Это отдельное приложение «Простые документы»
(интерфейс сейчас на русском языке). Название репозитория не означает
подтверждённое снятие лимитов подключений.

## Возможности

- DOCX: просмотр абзацев, замена текста абзаца и добавление нового.
- XLSX: выбор листа, изменение значений ячеек, добавление/удаление строк и столбцов.
- Масштаб содержимого 50–200%; браузерный жест масштабирования, где поддерживается.
- Кнопка сохранения с подтверждением изменения файла в Nextcloud.
- Автоматическое открытие мобильных DOCX/XLSX в нашей панели для допущенных
  пользователей; на компьютере остаётся штатный ONLYOFFICE.
- Маршрут Android Direct Editing ведёт в панель; иногда нужен отдельный вход
  в веб-окне. Разные Android-клиенты/WebView требуют проверки на своём устройстве.

## Совместимость и ограничения

| Компонент | Проверено / требуется установщиком |
| --- | --- |
| Nextcloud | 35; локальная интеграция проверена на 35.0.2 |
| Коннектор ONLYOFFICE | 10.2.1, включён и настроен с JWT |
| ONLYOFFICE Docs | Официальный Community 10.0.0-169, закреплённый Linux amd64 digest |
| Наше приложение | `onlyoffice_mobile` 0.2.0, экспериментальное |

Установка настраивается под другие серверы, домены, пути и команды `occ`,
включая контейнерный Nextcloud с доступным на хосте каталогом приложений.
**Другие версии Nextcloud/коннектора не проверены**; установщик их отклоняет.
Это переносимость конфигурации, а не обещание поддержки любых версий.

Важные файлы редактируйте на копиях. Замена абзаца DOCX удаляет его внутреннее
форматирование и встроенные объекты. XLSX показывает **A1:H20 выбранного листа**;
это ограниченная панель, а не полный табличный редактор. Список файлов показывает
корень личных «Файлов». Публичные ссылки/гости, сложные документы и весь набор
настольных функций не поддерживаются. Файлы только для чтения или с запретом
копирования/скачивания отклоняются. По умолчанию доступ разрешён администраторам;
дополнительные пользователи задаются точными UID.

Штатный мобильный Community-редактор остаётся доступен только для просмотра.
Коммерческий mobile addon не включён, снятие лимитов подключений не подтверждено,
образ проекта в GHCR не публиковался. Docker использует готовую официальную базу
по digest, а не полную компиляцию исходников. См. [исследование](MOBILE-RESEARCH.md),
[аудит исходников](SOURCE-AUDIT.md) и [проверки](VALIDATION.md).

## Установка и обновление

[Инструкция на русском](docs/INSTALL.ru.md) · [English guide](docs/INSTALL.en.md).
Укажите собственные адреса, пути, владельца файлов и команду `occ` в копии
[mobile.example.json](deployment/mobile.example.json). Переносимый установщик
не меняет адрес штатного ONLYOFFICE, прокси и существующие контейнеры.
Можно использовать работающий Docs либо отдельный экземпляр из
[compose.mobile.yaml](deployment/compose.mobile.yaml).

Обновление только интерфейса переносимой установки:

```sh
git pull --ff-only
sudo python3 scripts/update-mobile-panel.py --ui-only --config private/mobile.json
```

Режим сохраняет предыдущие UI-файлы и не запускает общий upgrade Nextcloud.
Полное обновление версии приложения требует отдельного рассмотрения:
`occ upgrade` может затронуть другие ожидающие обновления приложения.

## Состояние и структура проекта

Владелец подтвердил работу развёртывания, мобильного редактирования, сохранения,
масштаба и выбора листов. Локальные Docker/браузерные проверки подтверждают
сохранение реальных DOCX/XLSX через Nextcloud, отказы в доступе, проверку CSRF и
мобильные маршруты. Это не аудит безопасности и не гарантия от потери данных.
Восстановление на всех вариантах инфраструктуры не проверялось.

- `nextcloud-app/onlyoffice_mobile/`: исходники приложения Nextcloud.
- `prototype-mobile/plugin/`: исходники плагина, настраиваемого под ваш origin.
- `scripts/install-mobile-app.py`: переносимый установщик приложения и плагина.
- `deployment/compose.mobile.yaml`: необязательный отдельный Docs.
- `tests/`: проверки установщика и браузерные регрессии; запуск — в инструкциях.
- `prototype-mobile/`: ранний отдельный прототип; его backend не используется в Nextcloud.
- `deployment/NC-MOBILE-INSTALL.md`, `scripts/*nc*`, скрипты удаления/восстановления:
  историческое развёртывание **конкретного nc**, не общие команды установки.
