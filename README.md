# onlyoffice-unlim

Проект подготовки и проверки ONLYOFFICE 10 на nc. Название не означает
подтверждённое снятие всех ограничений.

Текущий результат: на nc собран локальный образ на закреплённой официальной базе
10.0.0-169. Изолированный staging на 127.0.0.1:18080 прошёл открытие, редактирование,
сохранение и скачивание документов; проверка повторена после пересоздания.
Рабочий ONLYOFFICE 9.2.1 не переключался.

Мобильный web DOCX остаётся только для просмотра. Исследование исходников и
варианты дальнейшей работы: MOBILE-RESEARCH.md и SOURCE-AUDIT.md.
Лимит реальных соединений и интеграция нового образа с Nextcloud не проверены.

Dockerfile упаковывает готовую официальную базу по digest. Это не полная
компиляция DocumentServer из исходников; её воспроизводимость не доказана.
В GHCR образ пока не опубликован. Production не переключать без завершения
проверок, резервного копирования и явного подтверждения пользователя.

Инструкции: RUNBOOK.md, DEMO-TEST.md, ACCEPTANCE.md, BACKUP-ROLLBACK.md.
Результаты: VALIDATION.md. Все private.env, artifacts и тестовые документы
исключены из Git. Не публиковать JWT, credentials и пользовательские файлы.

## Экспериментальный собственный интерфейс

В prototype-mobile/ добавлен отдельный локальный прототип для DOCX/XLSX на
открытом plugin API desktop-движка. Есть собственная панель для узкого экрана;
прошли эмулированные браузерные проверки изменения/сохранения и повторного
открытия. Это НЕ готовый mobile addon и НЕ интеграция Nextcloud. Ограничения и
протокол проверок описаны в prototype-mobile/README.md и TEST-RESULTS.md.
