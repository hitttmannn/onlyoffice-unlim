Статус на 22.10.2026: подготовлено локально; образ не собран, сервер не обследован,
редактирование и лимит не подтверждены. Рабочий 9.2.1 не затрагивался.
Доступ к nc и выполнение команд — вручную пользователем.

## Что здесь реализовано

Изолированный staging на 127.0.0.1:18080 с отдельными томами, JWT и ограничением
ресурсов; проверка ресурсов; фиксация исходников релиза и submodule SHA;
Dockerfile для упаковки уже готового upstream runtime по digest; базовые HTTP-тесты.
Это НЕ готовая сборка всех компонентов из исходников. Полная компиляция и
упаковка из исходников остаются отдельным этапом после аудита точных gitlinks,
зависимостей и лицензий. Побитовая воспроизводимость не доказана.

См. RESEARCH.md, RUNBOOK.md, ACCEPTANCE.md и BACKUP-ROLLBACK.md.
Ничто здесь не публикуется и не переключает Nextcloud автоматически.
